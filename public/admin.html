Vision Opticals

Admin panel — manage your frames, lenses and photos.

First time setup — do this once:

1

Go to github.com → your profile photo (top right) → Settings → scroll to the bottom → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token

2

Give it a name like Vision Opticals Admin. Under "Repository access" choose Only select repositories and pick vision-opticals-tvr. Under "Permissions" set Contents: Read and write. Click Generate token and copy the code that appears (starts with github_pat_).

3

Paste that token into the box above and click Sign in. Nothing is saved to the repo — the token only lives in your browser on this device.
