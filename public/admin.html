Setup guide

How to connect admin to your GitHub repo

1
Go to github.com → Settings → Developer settings → OAuth Apps → New OAuth App
2
Fill in:
Application name: Vision Opticals Admin
Homepage URL: https://visionopticalstvr.in
Callback URL: https://visionopticalstvr.in/admin.html
3
Click Register application. Copy the Client ID.
4
In admin.html find const CLIENT_ID = "" and paste your Client ID inside the quotes.
5
Go to GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token. Select scope: repo. Copy the token and paste it where it says const PAT = "".
6
Push all 3 files (index.html, admin.html, products.json) to your repo. Netlify will auto-deploy.
7
Visit visionopticalstvr.in/admin.html → Sign in → go to Photo uploads → drag your frame photos → click Upload → then click Copy path and paste it into the photo field when adding a frame.
8
For your shop front photo: upload it in Photo uploads, copy its path (e.g. images/shop.jpg), open index.html, find const SHOP_IMG = "" and paste the path there.
