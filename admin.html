Setup guide

How to enable GitHub login for this admin page

1
Go to github.com → Settings → Developer settings → OAuth Apps → New OAuth App
2
Fill in:
Application name: Vision Opticals Admin
Homepage URL: https://visionopticalstvr.in
Callback URL: https://visionopticalstvr.in/admin.html
3
Click Register application. Copy the Client ID shown on the next page.
4
In admin.html, find the line const CLIENT_ID = "" near the top of the script and paste your Client ID there.
5
You also need a GitHub Personal Access Token with repo scope so the admin can save to your repo.
Go to GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token
Select scope: repo → Generate → Copy the token.
Paste it in admin.html where it says const PAT = "".
6
Push admin.html, index.html, and products.json to your GitHub repo. Netlify will deploy automatically.
7
To add your shop photo: upload the image to your repo as images/shop.jpg, then in index.html find const SHOP_IMG = "" and change it to "images/shop.jpg".
